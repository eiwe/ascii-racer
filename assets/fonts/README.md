# Fonts

`HackNerdFontMono-Regular.ttf` and `HackNerdFontMono-Bold.ttf` are the Hack
typeface (https://sourcefoundry.org/hack/), patched with extra glyphs by Nerd
Fonts (https://www.nerdfonts.com/). Hack is licensed under the MIT License, with
the Bitstream Vera License covering the glyphs it derives from Bitstream Vera /
DejaVu; the Nerd Fonts patches are MIT. The files were copied from the Arch Linux
system package `ttf-hack-nerd`.

See `LICENSE-Hack.md` in this folder for the full licence text.
