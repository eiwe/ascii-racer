First prototype release of ASCII Racer: a 3D toy-car racer drawn entirely in text characters.

## What's in 0.1

- ASCII renderer with five glyph methods, adjustable glyph size and character "squeeze"
- Raycast-wheel car physics with four handling presets and a live tuning panel
- Arcade drift on the handbrake, with a small exit boost
- One circuit: a figure-of-eight with a bridge, a jump, sweepers and a hairpin, with a lap timer
- Isometric and rear chase cameras
- Keyboard and gamepad controls, with rumble

Controls and everything else are in the [README](https://github.com/eiwe/ascii-racer#readme).

## Downloads

| Platform | File | First run |
|---|---|---|
| Windows (x86-64) | `ascii-racer-0.1-windows-x86_64.zip` | Unzip, run `ascii-racer.exe`. Unsigned: choose "More info → Run anyway" in SmartScreen. |
| Linux (x86-64) | `ascii-racer-0.1-linux-x86_64.tar.gz` | Extract, run `./ascii-racer.x86_64`. |
| macOS (Intel and Apple Silicon) | `ascii-racer-0.1-macos-universal.zip` | Unzip, open `ASCII Racer.app`. Not notarised: approve it in System Settings → Privacy & Security. On Retina displays, press `=` to enlarge the characters. |

Needs a GPU with Vulkan (Windows, Linux), Direct3D 12 (Windows) or Metal (macOS).

## Known limitations

- On Retina Macs the characters start out very small, because the default glyph size is set for standard-density screens. Press `=` a few times to enlarge them. A Retina-aware default is planned for the next release.
- The Windows build has only been run under Wine, not on a Windows PC.
- Handling was tuned against scripted measurements, with limited hands-on driving so far.
- One track, one car, no opponents, no sound.
