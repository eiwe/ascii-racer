The game now opens on a demo reel with a logo intro, and macOS gets readable defaults on Retina displays.

## New in 0.2

- **Demo reel.** The game starts with the car driving itself round the circuit: a racing line, a handbrake drift through the hairpin, flat over the jump. The camera cuts between the isometric view, the chase camera and four new cinematic shots. Press any key, button or trigger to play; `Esc` returns to the reel.
- **Logo intro.** An "ASCII RACER" wordmark built from characters decodes in over the reel, with speed lines and a glint, then settles into a small corner title.
- **Retina default on macOS.** On a Retina display the game starts with 20 px glyphs, and the HUD and tuning panel text is doubled, so the screen reads as characters without adjusting anything.
- **Bridge halo.** In the isometric view, a round opening follows the car while it is behind the bridge, so you can still see it. (0.1 hid the whole deck, which looked like a rendering error.)
- **Ramp walls** now rise gradually from kerb height, removing a blunt wall end near the hairpin exit.
- `--play` skips the reel and starts on the grid.

Controls and everything else are in the [README](https://github.com/eiwe/ascii-racer#readme).

Needs a GPU with Vulkan (Windows, Linux), Direct3D 12 (Windows) or Metal (macOS).

## First launch on macOS

The macOS build is not signed with an Apple Developer ID, so macOS blocks it the first time. Either:

- Open the app, dismiss the warning, then go to System Settings → Privacy & Security and click **Open Anyway**; or
- after unzipping, run `xattr -dr com.apple.quarantine ~/Downloads/"ASCII Racer.app"` in Terminal (adjust the path).

## Known limitations

- The Retina default was written without a Mac to test on. If the characters look too small or too large, adjust them with `-` and `=`.
- The Windows build has only been run under Wine, not on a Windows PC.
- Handling was tuned against scripted measurements, with limited hands-on driving so far.
- One track, one car, no opponents, no sound.
