A calmer isometric camera, a camera hint at the start, a solid finish arch, remembered glyph size, and fixes for the web build, which is now playable online.

**Play in the browser:** https://eiwe.github.io/ascii-racer/

## Changed in 0.4.1

- **Calmer isometric camera.** In windows narrower than 21:9, the view still looks ahead of the car, but it now glides: it follows a smoothed direction of travel, eases into every move, and no longer zooms with speed. The car moves across the screen about a third less, and roughly half as much through the hairpin and the esses.
- **Camera hint.** On the first start of a session, a small note under the start lights shows the control that switches between the isometric and chase cameras. It holds for five seconds, then moves to the top left corner next to the debug menu hint. Pressing the camera control dismisses it early.
- **Solid finish arch.** The legs of the finish arch now collide where you see them; before, a car on the kerb could drive through a leg. The arch is a little wider, so the whole road is open between its legs.
- **Glyph size is remembered.** A size set with `-` and `=` is saved and restored at the next start, on every platform. Stepping back to the default clears it.

## Web build

- **Title music on first load.** Browsers keep a page silent until the first click or key press, and that first key used to start the race, so the title music was never heard. The web build now opens on a start screen; the first click or key begins the demo reel with its music. A gamepad button cannot unlock sound in a browser, so the screen asks for a click or a key.
- **Readable on Retina displays.** On a display with a device pixel ratio of 2 the web build now starts with 16 px glyphs, and the HUD text is scaled to match.
- **Settings are kept dependably.** The pause-menu settings, the glyph size and a saved `custom` handling preset are written to the browser's storage the moment they change, so closing the tab straight afterwards does not lose them.
- Sound, keyboard and gamepad have now been checked in Chrome and a Firefox-based browser.

Everything else is in the [README](https://github.com/eiwe/ascii-racer#readme).

The desktop builds need a GPU with Vulkan (Windows, Linux), Direct3D 12 (Windows) or Metal (macOS). The web build needs a desktop browser with WebGL 2.

## First launch on macOS

The macOS build is not signed with an Apple Developer ID, so macOS blocks it the first time. Either:

- Open the app, dismiss the warning, then go to System Settings → Privacy & Security and click **Open Anyway**; or
- after unzipping, run `xattr -dr com.apple.quarantine ~/Downloads/"ASCII Racer.app"` in Terminal (adjust the path).

## Known limitations

- The web build looks close to the desktop builds but not identical; night differs most. Rumble in the browser is untested.
- The opponent is a rival on the road, not yet a race: there is a start, but no lap count, finish or results.
- Night is experimental: the far side of a corner outside the headlight beam is sparse.
- Apart from the pause-menu settings, the glyph size and the `custom` handling preset, choices such as the lighting mode and the camera are not kept between runs.
- The `heavy` preset bottoms out on the jump landing.
- The Retina defaults on macOS are untested, and the Windows build has only been run under Wine, not on a Windows PC.
- One track, and one opponent at a time.
